# Состояние реализации

## Готово в первом инкременте

- Разделение Android-клиента и серверной интеграции.
- Backend-каркас FastAPI.
- JWT-авторизация устройства по регистрационному коду.
- API списка, карточки и закрытия заявки.
- Ожидание успешного ответа Client Base перед подтверждением закрытия.
- Идемпотентный ключ закрытия заявки.
- Android-каркас на Jetpack Compose.
- Экраны регистрации, списка и карточки заявки.
- Форма оплаты и вызов закрытия.
- Модульные тесты формирования данных оплаты.
